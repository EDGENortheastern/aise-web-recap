# 🌿 AISE Web Recap Technical Documentation 🌿

A simple and clean web project designed to practise core front-end skills, including layout, styling, and user interaction.

## ✨ Features

- 🎨 Styled using a custom colour palette
- 📱 Responsive and centred layout
- 🧭 Clear and minimal UI
- ⚡ Lightweight and fast

## 🎯 Purpose

This lesson focuses on:

- building structured HTML layouts;
- applying consistent styling using CSS;
- improving visual design with colour palettes;
- reinforcing clean and readable code practices;

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (if applicable)
